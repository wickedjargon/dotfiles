# font

> List, preview, and install fonts via fontconfig.
> Preview renders a sample image and opens it in the image viewer.

- List all installed font families:

`font`

- Filter the family list:

`font list {{mono}}`

- Preview an installed font:

`font preview {{JetBrains Mono}}`

- Try a font file before installing it:

`font preview {{~/dl/new.ttf}}`

- Install into ~/.local/share/fonts and refresh the cache:

`font install {{~/dl/new.ttf}}`
